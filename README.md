## Does the price of an artwork depend on where it is sold?
This project investigates cultural home bias in the international art market as part of my Bachelor's thesis at the Stockholm School of Economics.

Using art auction transaction data, I apply hedonic pricing models and country-pair regressions to examine differences in artwork prices across domestic and foreign markets.

### Data availability
The auction records used in this project are not included in this repository.
